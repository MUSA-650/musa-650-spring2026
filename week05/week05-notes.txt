Week05 Lecture
- data collection/sampling
    - balanced accuracy vs. category accuracy
        - if you train on a dataset that has a small unlabelled class, balanced accuracy will still be high because the majority of categories will be classified correctly
        - what is more desired: overall accuracy or accuracy for a specific class (i.e. melanoma vs. land use classification)
    - data augmentation
        - expanding a sparse sample in such a way that you're maintaining general patterns
        - makes minor changes to original datasets (rotations, flips, color adjustments, etc.)
        - biases and quality issues in original dataset still persist
        - finding an effective approach can be difficult
    - more data isn't always better
        - diminishing marginal returns
- model selection
    - urban heat island effect
        - tree-based model (i.e. random forest) to isolate driving forces
        - approach appropriate for a task, but not prediction
        - good time to use CNN instead
    - start with a baseline
        - use a less-powerful model (linear/logistic) to test relationships and see if DL is even necessary
    - what is your data structure?
        - what is the shape of the data (normally distr., clustered, etc.)
        - can the desired model handle non-normal data, outliers, multicollinearity, etc.?
