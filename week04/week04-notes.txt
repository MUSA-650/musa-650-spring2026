Week 04 Notes

Deep Neural Networks Video
- artificial "neurons" in sequences that are all connected to every neighbor
- each neuron can be thought of as an individual linear model providing weight/bias
    - linear regression only has a few "dials" (parameters) to modify, but neural networks have a LOT
- loss function --> how close did a neural network get to the correct answer
    - you try to minimize loss functions to optimize the model
- back propogation --> take a loss function (or similar single) and intelligently update parameters
    - repeat until you get closer to the correct answer
- data for neural networks
    - anything that can be converted to numbers can be used
        - pixels = darkness values/color values
        - sound = waveform (amplitude/frequencies)
        - text = tokens (pieces of words)
- supervised ML tasks
    - classification (is this a cat?)
    - regression (how heavy is this cat?)
    - detection (where is the cat in this image?)
    - generation (create a picture of a cat)
- importing data to neural network
    - from handwritten numbers:
        - create a 4x4 representative matrix of pixels
        - break each column of 4 pixels into 1x4 "strips"
        - feed each strip into the network
        - predict whether these patterns represent specific elements of a number
    - using convolution
        - allows for strong 2d classification 
    - figuring out what is the simplest way to get answers is crucial
        - determining a football player's team is harder in greyscale, easy with color
- large datasets and powerful computation required for ML
    - the primary strength of 'ai' is that it's extremely good at finding patterns in data
    - ML can add a lot of complexity to a system that's sometimes unnecessary
        - there aren't a lot of checks for answers once the model is trained
        - math is a key example
            - models don't perform raw computation, it predicts the answer based on its neural network
        - cancerous mole identification model
            - never detected cancer
            - image dataset included rulers in most cancerous mole images
            - model became a ruler detector
- ML core principles
    - models are targeted for well-understood problems
    - domain knowledge is commmon, let's use it
    - moodels must be useful for real-world applications 
    - we cannot assume that models are perfect
- ensuring proper use of ML in research
    - comprehensive verification
        - proper use of cross-validation
        - data leaks (data used for training is used for testing) are awful
        - analyze datasets first
        - ML is good at detecting major changes (i.e. brain shrinkage due to alzheimers)
            - more subtle symptoms are more difficult to classify
            - pre-processing of data (even file managements, potentially) can affect results
- model determinism (reproduceability)
    - determinism in ML model generation is actually not typically desired
    - having models change each time eventually helps them converge on a stronger answer
- models can be 95% accurate if:
    - you train it on a sample of 100 people (95 negative cases)
    - it predicts all 100 cases as negative

Week 04 Lecture
- ML tasks in remote sensing
    - image segmentation (pixel-wise classification)
        - used for land cover mapping
    - pixel-wise regression
        - produces a continuous output, rather than a categorical label
        - used for population density mapping
    - object detection
        - outputs bounding boxes and class labels
        - used for ship detection and autonomous driving monitoring
    - denoising
        - used for automated cloud removal (detects clouds and shadows)
    - inpainting
        - used to correct noisy images
            - i.e. due to landsat 7 scanline failure or clouds
    - super resolution
        - improves resolution of satellite data
    - example: rapid disaster response
        - international satellite law --> satellite operators must release images when natural disasters occur
        - steps: building prediction > pixelwise change > disaster impact index (DII)
    - common models in satellite imagery analysis
        - CNN (convolution neural network)
            - 
            - de-facto standard for computer vision and image processing 
        - U-Net (CNN with a "u-shape")
            - outputs are segmentations of images
        - Transformer 
            - cuts images into pieces, tokenizes them, and makes predictions to fill in the gaps
            - similar in concept to LLMs, just with pieces of an image
            - require a large amount of data
        - Foundation models
            - computer vision, natural language processing (NLP), speech recognition
        - Vector-Embeddings
            - massive feature sets --> turned into 64-dimensional
            - semantic encoding:
                - words encoded as vectors, each value represents a feature of the word
                    - vectors that are more equivalent = more similar words
            - google, clay, etc. have open-sourced their vector-embedding datasets
    - Workflow of Machine Learning
        - data acquisition/processing > feature engineering/selection > split > train > test > deploy
            - real-world processes often can be more complicated
    - unsupervised learning
        - remote sensing has a much more limited dataset than LLMs (images vs. text)
        - k-means
            - groups observations based on similarity
            - uses euclidean distance (scale matters, must normalize data)
            - struggles with data that has weird shapes/densities
